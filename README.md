# Codey — موقع تعريفي

موقع ساكن (HTML/CSS/JS بلا أي إطار عمل) لشركة **كودي للتطوير والاستشارة التقنية**.
الدومين المستهدف: `codeysaa.com`.

## الهيكل

```
index.html      الصفحة الرئيسية (الأقسام: Hero, Services, Work, Process, Stack, About, CTA, Contact)
css/style.css   نظام تصميم كامل (ثيم تقني داكن بدرجات الأزرق)
js/main.js      تفاعلات: عداد إحصاءات، Typewriter، Reveal on scroll، نموذج تواصل
assets/img/apps الأيقونات الحقيقية للأنظمة الثلاثة (سندك، عليان، للبلاد)
CNAME           لربط الموقع بالدومين عبر GitHub Pages
```

## أعمالنا المعروضة

- **تطبيق سندك الطبي** — دليل مرافق صحية وحجز مواعيد ومخيمات طبية (موقعه الحي: `snadk.codeysaa.com`).
- **نظام عليان** — إدارة بطولات ألعاب القوى ونتائج مباشرة.
- **تطبيق للبلاد** — تطبيق نقل محلي بثلاثة أدوار (مسافر/سائق/إدارة).

## التشغيل محليًا

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا ساكنًا بسيطًا:

```bash
npx serve .
```

## النشر

الموقع جاهز للاستضافة على أي خدمة ساكنة (GitHub Pages, Render, Netlify...).
ملف `CNAME` معدّ مسبقًا لدومين `codeysaa.com` في حال استُخدم GitHub Pages.
